# Build Instructions for MCEF ARM64 Wrapper\n\n## Prerequisites\n\n### Required Software\n1. **Java JDK 17+** (required for Minecraft 1.20.1)\n   - Download: https://adoptium.net/\n   - Verify: `java -version`\n\n2. **Git** (to clone the repository)\n   - Download: https://git-scm.com/\n   - Verify: `git --version`\n\n3. **Gradle** (included via wrapper, but you can install standalone)\n   - Optional: https://gradle.org/install/\n\n### Optional (for native ARM64 compilation)\n4. **Android NDK r25c** (for compiling native JNI libraries)\n   - Download: https://developer.android.com/ndk/downloads\n   - Set: `export ANDROID_NDK_HOME=/path/to/ndk`\n\n---\n\n## Step-by-Step Build Guide\n\n### Step 1: Clone the Repository\n\n```bash\n# Clone from GitHub\ngit clone https://github.com/fe44ek1243/mcef-arm64-builder.git\ncd mcef-arm64-builder\n```\n\n### Step 2: Verify Java Installation\n\n```bash\n# Check Java version\njava -version\n\n# You should see Java 17 or higher:\n# openjdk version \"17.0.x\" ...\n```\n\nIf you don't have Java 17+, download and install it from https://adoptium.net/\n\n### Step 3: Build the Mod JAR\n\n#### On Windows:\n```cmd\n# Run the Gradle build\ngradlew.bat buildArm64\n```\n\n#### On macOS/Linux:\n```bash\n# Make gradlew executable\nchmod +x ./gradlew\n\n# Run the Gradle build\n./gradlew buildArm64\n```\n\n**What this does:**\n- Downloads Forge 1.20.1 sources\n- Decompiles Minecraft code\n- Compiles Java source to bytecode\n- Packages everything into a JAR file\n\n### Step 4: Find the Built JAR\n\nAfter the build completes, the mod JAR will be at:\n\n```\nbuild/libs/mcef-arm64-1.20.1.jar\n```\n\n---\n\n## Installing the Mod\n\n### For Desktop (Windows/Mac/Linux)\n\n1. **Locate your Minecraft mods folder:**\n   - Windows: `%APPDATA%\\.minecraft\\mods`\n   - macOS: `~/Library/Application Support/minecraft/mods`\n   - Linux: `~/.minecraft/mods`\n\n2. **Copy the JAR:**\n   ```bash\n   cp build/libs/mcef-arm64-1.20.1.jar ~/.minecraft/mods/\n   ```\n\n3. **Launch Minecraft with Forge 1.20.1**\n   - The mod will load automatically\n\n### For Android (ZalithLauncher2)\n\n1. **On your Android device:**\n   - Open ZalithLauncher2\n   - Select or create a Forge 1.20.1 instance\n   - Tap \"Mods\" → \"Open Mods Folder\"\n\n2. **Copy the JAR to the mods folder:**\n   ```bash\n   # Via ADB (Android Debug Bridge)\n   adb push build/libs/mcef-arm64-1.20.1.jar /path/to/instance/mods/\n   \n   # Or copy manually via file manager\n   # Find: /storage/emulated/0/ZalithLauncher/instances/[instance]/mods/\n   ```\n\n3. **Launch the instance**\n   - Wrapper auto-activates on ARM64 devices\n\n---\n\n## Troubleshooting Build Issues\n\n### Issue: \"Java not found\"\n\n```\nError: Java version is not supported\n```\n\n**Solution:**\n1. Install JDK 17+: https://adoptium.net/\n2. Set JAVA_HOME environment variable:\n\n   **Windows:**\n   ```cmd\n   set JAVA_HOME=C:\\Program Files\\adoptium\\jdk-17.x.x\n   gradlew.bat buildArm64\n   ```\n\n   **macOS/Linux:**\n   ```bash\n   export JAVA_HOME=/path/to/jdk-17\n   ./gradlew buildArm64\n   ```\n\n### Issue: \"Permission denied\" on macOS/Linux\n\n```\nError: Permission denied: ./gradlew\n```\n\n**Solution:**\n```bash\nchmod +x ./gradlew\n./gradlew buildArm64\n```\n\n### Issue: \"Gradle build failed\"\n\n```\nBuild failed: Could not download ...\n```\n\n**Solution:**\n1. Check internet connection\n2. Clean and retry:\n   ```bash\n   ./gradlew clean buildArm64\n   ```\n3. If still failing, check GitHub issues: https://github.com/fe44ek1243/mcef-arm64-builder/issues\n\n### Issue: \"Out of memory\"\n\n```\nJava heap space exception\n```\n\n**Solution:**\nIncrease Gradle heap size:\n\n```bash\n# Windows\nset GRADLE_OPTS=-Xmx4g\ngradlew.bat buildArm64\n\n# macOS/Linux\nexport GRADLE_OPTS=-Xmx4g\n./gradlew buildArm64\n```\n\n### Issue: \"Compilation error\" in Java source\n\n```\nError: Could not compile sources\n```\n\n**Solution:**\n1. Ensure you have JDK 17+ (not JRE)\n2. Try clean build:\n   ```bash\n   ./gradlew clean buildArm64 --stacktrace\n   ```\n3. Report issue with full error log\n\n---\n\n## Build Variants\n\n### Full Build (Desktop + Android)\n```bash\n./gradlew build\n```\nOutput: `build/libs/mcef-arm64-1.20.1.jar`\n\n### ARM64 Build Only\n```bash\n./gradlew buildArm64\n```\nOutput: `build/libs/mcef-arm64-1.20.1.jar`\n\n### Download Forge Sources\n```bash\n./gradlew downloadForgeSource\n```\n\n### Apply ARM64 Patches\n```bash\n./gradlew applyPatches\n```\n\n### Compile Native Code\n```bash\n./gradlew buildNative\n```\n(Requires Android NDK)\n\n### Clean Build\n```bash\n./gradlew clean\n```\n\n---\n\n## Verify the Build\n\n### Check JAR was created:\n```bash\nls -lh build/libs/\n```\n\nYou should see:\n```\n-rw-r--r-- ... mcef-arm64-1.20.1.jar (size: ~5-10 MB)\n```\n\n### Check JAR contents:\n```bash\nunzip -l build/libs/mcef-arm64-1.20.1.jar | head -30\n```\n\nYou should see:\n```\nArchive:  build/libs/mcef-arm64-1.20.1.jar\n  Length     Date   Time    Name\n----------  ----   ----    ----\n     1234  08-28-26 07:30   META-INF/mods.toml\n     5678  08-28-26 07:30   com/mcef/arm64/McefArm64Mod.class\n     ...\n```\n\n---\n\n## Development Environment Setup (Optional)\n\nIf you want to edit and rebuild:\n\n### IntelliJ IDEA\n1. Subsequent builds: 2-5 minutes.\n\n**Q: Do I need Android NDK?**  \nA: No, it's optional. The wrapper has pre-compiled stubs. NDK is only needed if you modify C/C++ code.\n\n**Q: Can I build on my phone?**  \nA: Not easily. Use a PC/Mac/Linux for building, then transfer the JAR to your phone.\n\n**Q: What if the build fails?**  \nA: Check the error message, enable `--stacktrace`, and report on GitHub issues.\n\n**Q: Can I modify the source?**  \nA: Yes! Edit files in `src/main/java/`, then run `./gradlew buildArm64` to rebuild.\n"
